# Product Requirements Document

## Project Overview
**Name:** expense_splitter
**Type:** web_application
**Created:** 2026-11-01T19:44:13.444933

## Description
Build a minimal expense splitter. User authentication (email/password). Create a group expense, split it evenly among members, delete an expense. List all expenses for the logged-in user. (Type: web_app)

## Features
- authentication
- group_expense_creation
- expense_deletion
- expense_listing

## User Stories
### User Authentication
As a user, I want to create an account and log in so that I can access personalized features.

**Acceptance Criteria:** User can register, login, logout, and reset password

## Business Logic
- Create and manage group expenses
- Split expenses evenly among members
- List all expenses for the logged-in user
